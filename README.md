# Tehrani Moghaddam research site (offline)
Open `index.html` in any browser. No server, CDN, or network is needed. Files: css/styles.css, js/main.js.
Status: condensed first build. See the end of index.html (sources section) for what was verified.

## Font (B Koodak)
The site uses "B Koodak" through @font-face with relative paths. The font file is NOT bundled (it could not be downloaded here).
Put your licensed copy in `assets/fonts/` named `BKoodak.woff2` (or `.woff` / `.ttf`). If it is missing, the site falls back to Tahoma.
